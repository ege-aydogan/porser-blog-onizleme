# Porser blog önizlemesi

Porser web sitesi blog tasarım seçeneklerinin statik önizlemesi: porser-blog.nimvola.com

- Giriş sayfası dört seçenekten birini sorar; her sayfadaki seçici aynı yazıyı öbür seçeneklerde açar.
- Dosyalar sitenin yerel çalışma sürümünden alınmıştır; içerik örnek yazılardır.
- nginx ile sunulur (`Dockerfile`, `nginx.conf`). Bütün yanıtlar arama motorlarına kapalıdır.
